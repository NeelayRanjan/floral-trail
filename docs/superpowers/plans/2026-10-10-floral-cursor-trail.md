# Floral Cursor Trail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone Canvas 2D prototype page where hand-drawn-style floral ornament grows in the wake of the cursor and fades away, with switchable presets and a top slider bar exposing every tunable.

**Architecture:** Pointer → `PathSampler` (smoothed, evenly spaced path) → `Grower` (spine strands, tendrils, terminals, frills, blooms; seeded) → `Scene` (elements grouped into age cohorts) → `Renderer` (per-cohort offscreen buffers using the stroke-then-cut trick for fused outlines; cohorts composited oldest-first with occlusion masks and age fading). Pure logic modules have no DOM access and are unit-tested with `node --test`; hand-drawn motifs are extracted offline from PNGs by a Python + potrace pipeline into `motifs.json`.

**Tech Stack:** Vanilla ES modules, Canvas 2D, `node --test` (Node 24, no dependencies), Python 3 + Pillow + `potrace` CLI, Playwright MCP for visual checks, `python3 -m http.server` to serve.

**Spec:** `docs/superpowers/specs/2026-10-10-floral-cursor-trail-design.md`

## Global Constraints

- Standalone `prototype/` folder: `index.html` + vanilla ES modules, Canvas 2D, **no build step, no npm dependencies**.
- `geometry.js`, `grower.js`, `tendril.js`, `scene.js`, `shapes.js`, `noise.js`, `rng.js`, `input.js`, `presets.js`, `colour.js`, `motifs.js` (library part) must not touch the DOM or canvas.
- All randomness through the seeded RNG (`rng.js`); same seed + same input ⇒ same composition.
- Every tunable is a schema parameter in `presets.js` and therefore gets a control in the top bar automatically.
- Repo is local/private: never add a remote or push.
- Reference PNGs are used for extraction during feasibility only (copyright out of scope for this phase).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Serve with `python3 -m http.server 8137 -d prototype` → `http://localhost:8137/`.
- URL params: `preset`, `seed`, `autodraw=1`, `fixedstep=1`, `warmup=<seconds>`, `pause=1`.

## Review Focus

1. **Cursor leaves the window or moves onto the panel mid-stroke** → the strand ends cleanly with a terminal; no straight streak joins exit and re-entry points. (Pinned by Task 7 sampler break tests and Task 9 break test; wired in Task 10.)
2. **Tab hidden / frame stall then resumed** → no burst of growth and no instant fade; frame `dt` is clamped to 50 ms. (Pinned by Task 7 `clampDt` test.)
3. **Extreme or inverted slider values** (min > max, spacing 0, all terminal weights 0, tiny cohort window) → keeps running without hanging or throwing. (Pinned by Task 6 zero-weight test and Task 9 extreme-values test.)
4. **Long sessions of scribbling** → element count and buffers stay bounded: cull drops cohorts and their buffers, `maxElements` caps spawns. (Pinned by Task 4 cull test and Task 9 max-elements test.)
5. **Pasting malformed or out-of-range settings JSON** → invalid values ignored, ranges clamped, rendering unaffected. (Pinned by Task 3 `sanitize` test.)

`prototype/src/rng.js`:
```js
// Seeded PRNG (mulberry32) plus helpers. Same seed => same sequence.
export function createRng(seed) {
  let state = (seed >>> 0) || 0x9e3779b9;
  function next() {
    state = (state + 0x6d2b79f5) >>> 0;
    let t = state;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  }
  return {
    next,
    range: (min, max) => min + (max - min) * next(),
    int: (min, max) => Math.floor(min + (max - min + 1) * next()),
    chance: (p) => next() < p,
    sign: () => (next() < 0.5 ? -1 : 1),
    pick: (arr) => arr[Math.floor(next() * arr.length)],
    weighted(entries) {
      let total = 0;
      for (const [, w] of entries) total += Math.max(0, w);
      if (total <= 0) return null;
      let r = next() * total;
      let last = null;
      for (const [value, w] of entries) {
        if (w <= 0) continue;
        last = value;
        r -= w;
        if (r < 0) return value;
      }
      return last;
    },
    fork: () => createRng(Math.floor(next() * 4294967296)),
  };
}
```

`prototype/src/noise.js`:
```js
import { createRng } from './rng.js';

const SIZE = 1024;

// Smooth 1D value noise in [-1, 1]; offset x by a per-element seed for independent streams.
export function createNoise1D(seed) {
  const rng = createRng(seed);
  const table = new Float32Array(SIZE);
  for (let i = 0; i < SIZE; i++) table[i] = rng.next() * 2 - 1;
  return function noise(x) {
    const i = Math.floor(x);
    const f = x - i;
    const a = table[i & (SIZE - 1)];
    const b = table[(i + 1) & (SIZE - 1)];
    const t = f * f * (3 - 2 * f);
    return a + (b - a) * t;
  };
}
```

```js
// Polyline math in screen space (y down). Normals are the tangent rotated +90°.

export const dist = (a, b) => Math.hypot(b.x - a.x, b.y - a.y);
export const ordered = (a, b) => (a <= b ? [a, b] : [b, a]);

export function cumulativeLengths(points) {
  const cum = new Array(points.length);
  let s = 0;
  for (let i = 0; i < points.length; i++) {
    if (i > 0) s += dist(points[i - 1], points[i]);
    cum[i] = s;
  }
  return cum;
}

// Evenly respaced copy of a polyline (by arc length); keeps the first and last points.
export function resample(points, spacing) {
  if (points.length < 2) return points.map((p) => ({ x: p.x, y: p.y }));
  const out = [{ x: points[0].x, y: points[0].y }];
  let carry = 0;
  for (let i = 1; i < points.length; i++) {
    const a = points[i - 1], b = points[i];
    const seg = dist(a, b);
    let t = spacing - carry;
    while (t <= seg) {
      const u = t / seg;
      out.push({ x: a.x + (b.x - a.x) * u, y: a.y + (b.y - a.y) * u });
      t += spacing;
    }
    carry = seg - (t - spacing);
  }
  const last = points[points.length - 1];
  if (dist(out[out.length - 1], last) > 1e-6) out.push({ x: last.x, y: last.y });
  return out;
}

function tangentAt(points, i) {
  const n = points.length;
  const a = points[Math.max(0, i - 1)], b = points[Math.min(n - 1, i + 1)];
  const dx = b.x - a.x, dy = b.y - a.y;
  const len = Math.hypot(dx, dy) || 1;
  return { x: dx / len, y: dy / len };
}

export function normals(points) {
  return points.map((_, i) => {
    const t = tangentAt(points, i);
    return { x: -t.y, y: t.x };
  });
}

export function sampleAt(points, cum, s) {
  const n = points.length;
  if (n === 1) return { point: { x: points[0].x, y: points[0].y }, heading: 0, normal: { x: 0, y: 1 } };
  let i = 1;
  while (i < n - 1 && cum[i] < s) i++;
  const a = points[i - 1], b = points[i];
  const seg = cum[i] - cum[i - 1] || 1;
  const u = Math.min(1, Math.max(0, (s - cum[i - 1]) / seg));
  const heading = Math.atan2(b.y - a.y, b.x - a.x);
  return {
    point: { x: a.x + (b.x - a.x) * u, y: a.y + (b.y - a.y) * u },
    heading,
    normal: { x: -Math.sin(heading), y: Math.cos(heading) },
  };
}

// Prefix of a polyline up to arc length `len`, interpolating the final point.
export function truncate(points, cum, len) {
  const n = points.length;
  if (len >= cum[n - 1]) return { points, cum };
  let i = 0;
  while (i < n - 1 && cum[i + 1] <= len) i++;
  const outP = points.slice(0, i + 1);
  const outC = cum.slice(0, i + 1);
  if (len > cum[i] && i < n - 1) {
    const a = points[i], b = points[i + 1];
    const u = (len - cum[i]) / (cum[i + 1] - cum[i]);
    outP.push({ x: a.x + (b.x - a.x) * u, y: a.y + (b.y - a.y) * u });
    outC.push(len);
  }
  return { points: outP, cum: outC };
}

// Integrates a curve from (x, y). curvature(s) is in 1/px; positive turns toward +normal.
// droop pulls the heading toward straight down (screen +y).
export function curvePath({ x, y, heading, length, curvature, droop = 0, step = 3 }) {
  const points = [{ x, y }];
  let h = heading;
  const n = Math.max(1, Math.ceil(length / step));
  const ds = length / n;
  for (let i = 1; i <= n; i++) {
    h += curvature((i - 0.5) * ds) * ds;
    if (droop) h += droop * (ds / 100) * Math.sin(Math.PI / 2 - h);
    x += Math.cos(h) * ds;
    y += Math.sin(h) * ds;
    points.push({ x, y });
  }
  return { points, endHeading: h };
}

export function ribbonSides(points, halfL, halfR) {
  const ns = normals(points);
  const left = [], right = [];
  for (let i = 0; i < points.length; i++) {
    const p = points[i], n = ns[i];
    left.push({ x: p.x + n.x * halfL[i], y: p.y + n.y * halfL[i] });
    right.push({ x: p.x - n.x * halfR[i], y: p.y - n.y * halfR[i] });
  }
  return { left, right };
}

const CAP_SEGMENTS = 12;

// Semicircle from `from` to `to` bulging along `tangent` (endpoints excluded).
function roundCap(from, to, tangent) {
  const c = { x: (from.x + to.x) / 2, y: (from.y + to.y) / 2 };
  const r = dist(from, to) / 2;
  if (r < 1e-6) return [];
  const ux = (from.x - c.x) / r, uy = (from.y - c.y) / r;
  const out = [];
  for (let k = 1; k < CAP_SEGMENTS; k++) {
    const th = (k / CAP_SEGMENTS) * Math.PI;
    out.push({
      x: c.x + r * (ux * Math.cos(th) + tangent.x * Math.sin(th)),
      y: c.y + r * (uy * Math.cos(th) + tangent.y * Math.sin(th)),
    });
  }
  return out;
}

// Closed outline polygon (for filling) plus stroke runs that skip 'open' ends,
// so chunks of one ribbon drawn in different buffers join without a seam line.
export function ribbonOutline(points, left, right, capStart, capEnd) {
  const n = points.length;
  const endTan = tangentAt(points, n - 1);
  const startTan = tangentAt(points, 0);
  const endCap = capEnd === 'round' ? roundCap(left[n - 1], right[n - 1], endTan) : [];

  let runs;
  if (capStart !== 'open' && capEnd !== 'open') runs = [{ points: polygon, closed: true }];
  else if (capStart === 'open' && capEnd === 'open') runs = [{ points: left, closed: false }, { points: rightRev, closed: false }];
  else if (capEnd === 'open') runs = [{ points: [...rightRev, ...startCap, ...left], closed: false }];
  else runs = [{ points: [...left, ...endCap, ...rightRev], closed: false }];
  return { polygon, runs };
}
```

```js
function parseHex(hex) {
  const s = hex.replace('#', '');
  const full = s.length === 3 ? s.split('').map((c) => c + c).join('') : s;
  return [0, 2, 4].map((i) => parseInt(full.slice(i, i + 2), 16));
}

export function mixHex(a, b, t) {
  const A = parseHex(a), B = parseHex(b);
  const k = Math.min(1, Math.max(0, t));
  return '#' + A.map((v, i) => Math.round(v + (B[i] - v) * k).toString(16).padStart(2, '0')).join('');
}
```

`prototype/src/scene.js`:
```js
// Elements are grouped into cohorts by birth time. A cohort is rendered as one buffer,
// so elements inside it fuse; separate cohorts layer by age.
export class Scene {
  constructor() {
    this.clear();
  }

  clear() {
    this.cohorts = [];
    this.current = { front: null, back: null };
    this.count = 0;
    this.nextId = 1;
  }

  cohortFor(track, now, windowSec) {
    let c = this.current[track];
    if (!c || now - c.start >= windowSec) {
      c = { id: this.nextId++, track, start: now, end: now, elements: [], version: 0, renderState: null };
      this.cohorts.push(c);
      this.current[track] = c;
    }
    return c;
  }

  add(el, track, now, windowSec) {
    const c = this.cohortFor(track, now, windowSec);
    el.cohort = c;
    c.elements.push(el);
    c.version++;
    c.end = Math.max(c.end, el.born + el.growDuration);
    this.count++;
    return c;
  }

  touch(cohort) {
    cohort.version++;
  }

  isGrowing(cohort, now) {
    return now < cohort.end;
  }

  cull(now, lifetime) {
    const removed = [];
    const kept = [];
    for (const c of this.cohorts) (now - c.start > lifetime ? removed : kept).push(c);
    if (!removed.length) return removed;
    this.cohorts = kept;
    for (const c of removed) {
      this.count -= c.elements.length;
      c.renderState = null;
      if (this.current[c.track] === c) this.current[c.track] = null;
    }
    return removed;
  }
}

export class DensityGrid {
  constructor(cell = 48) {
    this.cell = cell;
    this.cells = new Map();
  }
  key(x, y) {
    return `${Math.floor(x / this.cell)},${Math.floor(y / this.cell)}`;
  }
  count(x, y) {
    return this.cells.get(this.key(x, y)) || 0;
  }
  add(x, y) {
    const k = this.key(x, y);
    this.cells.set(k, (this.cells.get(k) || 0) + 1);
    return k;
  }
  remove(k) {
    const v = (this.cells.get(k) || 0) - 1;
    if (v > 0) this.cells.set(k, v);
    else this.cells.delete(k);
  }
  clear() {
    this.cells.clear();
  }
}

export function cohortAlpha(age, lifetime, fadeStart) {
  const t = age / lifetime;
  if (t <= fadeStart) return 1;
  if (t >= 1) return 0;
  const u = (t - fadeStart) / (1 - fadeStart);
  return 1 - u * u * (3 - 2 * u);
}

export function ageStep(age, lifetime, steps) {
  return Math.min(steps, Math.max(0, Math.floor((age / lifetime) * steps)));
}
```

```js
import { ribbonSides, ribbonOutline, truncate } from './geometry.js';

export const clamp01 = (t) => Math.min(1, Math.max(0, t));
export function smoothstep(a, b, x) {
  if (b === a) return x >= b ? 1 : 0;
  const t = clamp01((x - a) / (b - a));
  return t * t * (3 - 2 * t);
}
export const easeOutCubic = (t) => 1 - Math.pow(1 - t, 3);
export function easeOutBack(t) {
  const c1 = 1.70158, c3 = c1 + 1;
  return 1 + c3 * Math.pow(t - 1, 3) + c1 * Math.pow(t - 1, 2);
}
// Brush-like taper: pointed at d = 0, full width by d = len.
const sineTaper = (d, len) => (len > 0 ? Math.sin(clamp01(d / len) * Math.PI / 2) : 1);

export function growProgress(el, now) {
  if (now < el.born) return 0;
  if (!(el.growDuration > 0)) return 1;
  return clamp01((now - el.born) / el.growDuration);
}

// g = arc length from the strand start; distToEnd = arc length to this chunk's end.
export function spineHalfWidth(params, noise, el, g, distToEnd) {
  let half = 0.5 * params.spineWidth * Math.max(0.15, 1 + params.widthNoise * noise(g / 180 + el.seed * 3.1));
  half *= sineTaper(g, params.tailTaper);
  if (el.taperEnd) half *= sineTaper(distToEnd, params.tipTaper);
  return half;
}

export function tendrilHalfWidth(params, scale, t) {
  const start = 0.5 * params.spineWidth * params.tendrilWidth * scale;
  return start * (1 + (params.tendrilEndWidth - 1) * Math.pow(clamp01(t), 0.8));
}

function wobble(params, noise, g, seed) {
  return params.wobbleLow * noise(g / Math.max(1, params.wobbleLowWave) + seed)
    + params.roughness * noise(g / Math.max(0.5, params.roughnessWave) + seed + 211);
}

export function ribbonShape(el, params, noise, now) {
  const isSpine = el.role === 'spine';
  let points = el.points, cum = el.cum, growTaper = 0;
  if (!isSpine) {
    const p = easeOutCubic(growProgress(el, now));
    if (p <= 0) return null;
    if (p < 1) ({ points, cum } = truncate(el.points, el.cum, el.length * p));
    growTaper = 1 - smoothstep(0.8, 1, p);
  }
  const n = points.length;
  if (n < 2) return null;
  const total = cum[n - 1];
  const halfL = new Array(n), halfR = new Array(n);
  const seedL = el.seed * 13.7, seedR = seedL + 400;
  for (let i = 0; i < n; i++) {
    const s = cum[i];
    const g = isSpine ? el.sOffset + s : s;
    let half;
    if (isSpine) half = spineHalfWidth(params, noise, el, g, total - s);
    else {
      half = tendrilHalfWidth(params, el.scale, s / el.length);
      if (growTaper > 0) half *= 1 - growTaper * (1 - sineTaper(total - s, 30 * el.scale));
    }
    const f = Math.min(1, half / 2); // keep wobble from fattening tapered points
    halfL[i] = Math.max(0, half + f * wobble(params, noise, g, seedL));
    halfR[i] = Math.max(0, half + f * wobble(params, noise, g, seedR));
  }
  const { left, right } = ribbonSides(points, halfL, halfR);
  const capStart = isSpine ? (el.sOffset === 0 ? 'flat' : 'open') : el.capStart;
  const capEnd = isSpine ? (el.taperEnd ? 'flat' : 'open') : el.capEnd;
  const { polygon, runs } = ribbonOutline(points, left, right, capStart, capEnd);
  return { fill: { rings: [polygon], rule: 'nonzero' }, runs, ink: null };
}

export function blobShape(el, params, noise, now) {
  const p = growProgress(el, now);
  if (p <= 0) return null;
  const r = el.rel * params.ballSize * params.spineWidth * params.tendrilWidth * 0.5 * Math.max(0, easeOutBack(p));
  if (r < 0.3) return null;
  const ring = [];
  const N = 28;
  for (let i = 0; i < N; i++) {
    const a = (i / N) * Math.PI * 2;
    const rr = r + params.roughness * noise(a * 3 + el.x * 0.01);
    ring.push({ x: el.x + Math.cos(a) * rr, y: el.y + Math.sin(a) * rr });
  }
  return { fill: { rings: [ring], rule: 'nonzero' }, runs: [{ points: ring, closed: true }], ink: null };
}

export function motifShape(el, motif, params, now) {
  if (!motif) return null;
  const p = growProgress(el, now);
  if (p <= 0) return null;
  const size = el.size * params.motifScale * Math.max(0, easeOutBack(p));
  if (size < 0.5) return null;
  const ca = Math.cos(el.angle), sa = Math.sin(el.angle);
  const tf = ([u, v]) => {
    const vv = v * el.flip;
    return { x: el.x + (u * ca - vv * sa) * size, y: el.y + (u * sa + vv * ca) * size };
  };
  const rings = motif.silhouette.map((r) => r.map(tf));
  const ink = motif.ink && motif.ink.length ? motif.ink.map((r) => r.map(tf)) : null;
  return { fill: { rings, rule: 'evenodd' }, runs: rings.map((points) => ({ points, closed: true })), ink };
}

export function shapeBounds(shapes) {
  let minX = Infinity, minY = Infinity, maxX = -Infinity, maxY = -Infinity;
  const visit = (pts) => {
    for (const p of pts) {
      if (p.x < minX) minX = p.x;
      if (p.y < minY) minY = p.y;
      if (p.x > maxX) maxX = p.x;
      if (p.y > maxY) maxY = p.y;
    }
  };
  for (const s of shapes) {
    for (const r of s.fill.rings) visit(r);
    for (const run of s.runs) visit(run.points);
    if (s.ink) for (const r of s.ink) visit(r);
  }
  return { minX, minY, maxX, maxY };
}
```

```js
import { curvePath, cumulativeLengths, sampleAt, ordered } from './geometry.js';
import { tendrilHalfWidth } from './shapes.js';

const DEG = Math.PI / 180;
export const TERMINALS = ['curl', 'ball', 'hook', 'bud', 'leaf', 'flower'];
const WEIGHT_KEYS = { curl: 'wCurl', ball: 'wBall', hook: 'wHook', bud: 'wBud', leaf: 'wLeaf', flower: 'wFlower' };
const PROCEDURAL = new Set(['curl', 'ball', 'hook']);

export function pickTerminal(params, rng, hasMotif) {
  const entries = TERMINALS.map((t) => [t, PROCEDURAL.has(t) || hasMotif(t) ? params[WEIGHT_KEYS[t]] : 0]);
  return rng.weighted(entries) ?? 'curl';
}

// Body curvature k0 ramping to k1 near the end with exponent p (higher p = later, tighter scroll).
export function curvatureProfile(length, k0, k1, p) {
  return (s) => k0 + (k1 - k0) * Math.pow(Math.min(1, Math.max(0, s / length)), p);
}

export function motifElement(motif, x, y, angle, scale, rng, born, growDuration) {
  return {
    kind: 'motif', id: motif.id, x, y, angle,
    size: motif.baseSize * scale * rng.range(0.85, 1.15),
    flip: rng.sign(), born, growDuration,
  };
}

export function buildTendril(opts) {
  const { x, y, heading, side, params: P, rng, now, hasMotif, pickMotif } = opts;
  const scale = opts.scale ?? 1;
  const depth = opts.depth ?? 0;
  const [lenLo, lenHi] = ordered(P.lengthMin, P.lengthMax);
  const length = Math.max(12, (opts.length ?? rng.range(lenLo, lenHi)) * scale);
  const [dLo, dHi] = ordered(P.departMin, P.departMax);
  const depart = rng.range(dLo, dHi) * DEG;
  const terminal = opts.terminal ?? pickTerminal(P, rng, hasMotif);
  const loopBack = opts.loopBack ?? rng.chance(P.loopBackChance);

  // Loop-back: an arc that turns 2*depart (+ margin) back toward the parent, crossing it.
  const bend = loopBack
    ? (-side * (2 * depart + 0.6)) / (0.75 * length)
    : ((rng.chance(P.outwardCurlChance) ? side : -side) * P.bodyBend) / length;
  const turn = Math.sign(bend) || side;
  const curlR = Math.max(1, P.curlRadius * Math.sqrt(scale));
  let k1 = bend, p = 1;
  if (terminal === 'curl' || terminal === 'ball') { k1 = turn / curlR; p = P.curlRamp; }
  else if (terminal === 'hook') { k1 = turn / (curlR * 0.8); p = P.curlRamp * 2.5; }
  const curvature = curvatureProfile(length, bend, k1, p);
  const { points, endHeading } = curvePath({ x, y, heading: heading + side * depart, length, curvature, droop: P.droop });
  const growDuration = P.growTime * rng.range(0.8, 1.2) * Math.sqrt(scale);
  const ribbon = {
    kind: 'ribbon', role: 'tendril', points, cum: cumulativeLengths(points), length, scale, terminal,
    seed: rng.range(0, 500), born: now, growDuration, capStart: 'flat', capEnd: 'round',
  };
  const out = [ribbon];

  const end = points[points.length - 1];
  const endBorn = now + growDuration * 0.85;
  if (terminal === 'ball') {
    out.push({ kind: 'blob', x: end.x, y: end.y, rel: scale, born: endBorn, growDuration: 0.35 });
  } else if (!PROCEDURAL.has(terminal)) {
    const m = pickMotif(terminal, rng);
    if (m) out.push(motifElement(m, end.x, end.y, endHeading, Math.sqrt(scale), rng, endBorn, 0.6));
  }

  if (P.frillChance > 0 && hasMotif('frill')) {
    const spacing = Math.max(10, P.frillSpacing) * scale;
    for (let s = length * 0.2; s < length * 0.85; s += spacing * rng.range(0.7, 1.3)) {
      if (!rng.chance(P.frillChance)) continue;
      const at = sampleAt(points, ribbon.cum, s);
      const k = curvature(s);
      const outer = k === 0 ? rng.sign() : -Math.sign(k);
      const half = tendrilHalfWidth(P, scale, s / length);
      const m = pickMotif('frill', rng);
      out.push(motifElement(
        m,
        at.point.x + at.normal.x * outer * half,
        at.point.y + at.normal.y * outer * half,
        at.heading + outer * (Math.PI / 2 - 0.7),
        0.6 * scale, rng, now + growDuration * (s / length), 0.5,
      ));
    }
  }

  if (depth === 0 && rng.chance(P.subTendrilChance)) {
    const s = length * rng.range(0.3, 0.6);
    const at = sampleAt(points, ribbon.cum, s);
    const k = curvature(s);
    out.push(...buildTendril({
      ...opts, x: at.point.x, y: at.point.y, heading: at.heading,
      side: k === 0 ? rng.sign() : -Math.sign(k), scale: scale * 0.55, depth: 1,
      terminal: undefined, length: undefined, loopBack: false, now: now + growDuration * (s / length),
    }));
  }
  return out;
}
```

```js
import { dist } from './geometry.js';

// Turns a stream of positions into evenly spaced path points; a { break: true } marker splits strands.
export class PathSampler {
  constructor(spacing = 3, jump = 220) {
    this.spacing = spacing;
    this.jump = jump;
    this.last = null;
    this.carry = 0;
    this.queue = [];
  }

  push(x, y) {
    const p = { x, y };
    if (!this.last) {
      this.last = p;
      this.carry = 0;
      this.queue.push({ x, y });
      return;
    }
    const d = dist(this.last, p);
    if (d > this.jump) {
      this.breakStrand();
      this.push(x, y);
      return;
    }
    let t = this.spacing - this.carry;
    while (t <= d) {
      const u = t / d;
      this.queue.push({ x: this.last.x + (x - this.last.x) * u, y: this.last.y + (y - this.last.y) * u });
      t += this.spacing;
    }
    this.carry = d - (t - this.spacing);
    this.last = p;
  }

  breakStrand() {
    if (this.last) this.queue.push({ break: true });
    this.last = null;
    this.carry = 0;
  }

  take() {
    const q = this.queue;
    this.queue = [];
    return q;
  }
}

// Exponential smoothing of the cursor (time constant in ms) plus a smoothed speed estimate.
export class Smoother {
  constructor() {
    this.reset();
  }
  reset() {
    this.pos = null;
    this.speed = 0;
  }
  update(target, dt, tauMs) {
    if (!this.pos) {
      this.pos = { x: target.x, y: target.y };
      return this.pos;
    }
    const a = tauMs <= 0 ? 1 : 1 - Math.exp((-dt * 1000) / tauMs);
    const next = { x: this.pos.x + (target.x - this.pos.x) * a, y: this.pos.y + (target.y - this.pos.y) * a };
    const v = dist(this.pos, next) / Math.max(dt, 1e-4);
    this.speed += (v - this.speed) * Math.min(1, dt * 8);
    this.pos = next;
    return next;
  }
}

// Synthetic cursor: a Lissajous wander with warped time so it alternates sweeps and near-stops.
export function autoDrawPosition(t, width, height, seed = 1) {
  const ph = seed * 1.618;
  const tt = 0.5 * t + 0.64 * Math.sin(0.75 * t + ph); // d(tt)/dt = 0.5 + 0.48 cos(...) > 0
  const x = width / 2 + width * 0.36 * Math.sin(tt * 0.9 + ph) + width * 0.08 * Math.sin(tt * 2.3 + ph * 2);
  const y = height / 2 + height * 0.32 * Math.sin(tt * 1.3 + ph * 0.5) + height * 0.06 * Math.cos(tt * 3.1);
  return { x, y };
}

export const clampDt = (raw) => Math.min(0.05, Math.max(0, raw));
```

```python
#!/usr/bin/env python3
"""Extract hand-drawn motifs from line-art PNGs into normalised vector shapes.

Usage: python3 tools/extract_motifs.py [manifest] [out_json] [preview_png]

Each motif yields a silhouette (ink + enclosed areas, thin stems removed) and interior ink
detail, traced with potrace and normalised so the anchor is the origin, the attach direction
is +x and the silhouette's furthest point is at distance 1.
"""
import json
import math
import os
import subprocess
import sys
import tempfile
from collections import deque

from PIL import Image, ImageChops, ImageDraw, ImageFilter

HERE = os.path.dirname(os.path.abspath(__file__))
ROOT = os.path.dirname(HERE)


def ink_mask(img, threshold):
    """255 where the pixel is ink (darker than threshold)."""
    return img.convert('L').point(lambda v: 255 if v < threshold else 0)


def dilate(mask, r):
    return mask.filter(ImageFilter.MaxFilter(2 * r + 1)) if r > 0 else mask


def erode(mask, r):
    return mask.filter(ImageFilter.MinFilter(2 * r + 1)) if r > 0 else mask


def largest_component(mask):
    w, h = mask.size
    px = list(mask.getdata())
    label = [0] * (w * h)
    best, best_size, cur = 0, 0, 0
    for i in range(w * h):
        if not px[i] or label[i]:
            continue
        cur += 1
        size = 0
        q = deque([i])
        label[i] = cur
        while q:
            j = q.popleft()
            size += 1
            x, y = j % w, j // w
            for k in (j - 1 if x > 0 else -1, j + 1 if x < w - 1 else -1,
                      j - w if y > 0 else -1, j + w if y < h - 1 else -1):
                if k >= 0 and px[k] and not label[k]:
                    label[k] = cur
                    q.append(k)
        if size > best_size:
            best, best_size = cur, size
    out = Image.new('L', (w, h), 0)
    out.putdata([255 if best and lab == best else 0 for lab in label])
    return out


def silhouette(ink, close_r, open_r):
    """Ink plus everything it encloses; an opening drops thin stems and whiskers."""
    closed = erode(dilate(ink, close_r), close_r)
    w, h = closed.size
    padded = Image.new('L', (w + 2, h + 2), 0)
    padded.paste(closed, (1, 1))
    ImageDraw.floodfill(padded, (0, 0), 128)
    sil = padded.crop((1, 1, w + 1, h + 1)).point(lambda v: 0 if v == 128 else 255)
    sil = dilate(erode(sil, open_r), open_r)
    return largest_component(sil)


def interior_ink(ink, sil, stroke_r):
    return ImageChops.multiply(ink, erode(sil, stroke_r))


def trace(mask, turd=8, alphamax=1.0):
    """potrace a 255-foreground mask; returns rings in image coordinates (y down)."""
    with tempfile.TemporaryDirectory() as d:
        pbm = os.path.join(d, 'm.pbm')
        out = os.path.join(d, 'm.json')
        mask.point(lambda v: 0 if v else 255).convert('1', dither=Image.Dither.NONE).save(pbm)
        subprocess.run(['potrace', pbm, '-b', 'geojson', '-t', str(turd), '-a', str(alphamax), '-o', out],
                       check=True)
        with open(out) as f:
            data = json.load(f)
    h = mask.size[1]
    rings = []
    for feat in data['features']:
        geom = feat['geometry']
        polys = [geom['coordinates']] if geom['type'] == 'Polygon' else geom['coordinates']
        for poly in polys:
            for ring in poly:
                rings.append([(x, h - y) for x, y in ring])  # potrace geojson is y-up
    return rings


def rdp(points, eps):
    if len(points) < 3:
        return points
    keep = [False] * len(points)
    keep[0] = keep[-1] = True
    stack = [(0, len(points) - 1)]
    while stack:
        i, j = stack.pop()
        ax, ay = points[i]
        bx, by = points[j]
        dx, dy = bx - ax, by - ay
        length = math.hypot(dx, dy) or 1e-9
        best, idx = 0.0, -1
        for k in range(i + 1, j):
            px, py = points[k]
            dd = abs(dy * (px - ax) - dx * (py - ay)) / length
            if dd > best:
                best, idx = dd, k
        if best > eps:
            keep[idx] = True
            stack += [(i, idx), (idx, j)]
    return [p for p, k in zip(points, keep) if k]


def normalise(rings, anchor, angle_deg, scale):
    a = math.radians(angle_deg)
    ca, sa = math.cos(-a), math.sin(-a)
    ax, ay = anchor
    out = []
    for ring in rings:
        pts = []
        for x, y in ring:
            dx, dy = x - ax, y - ay
            pts.append([round((dx * ca - dy * sa) / scale, 4), round((dx * sa + dy * ca) / scale, 4)])
        out.append(pts)
    return out


def process(entry, root=ROOT):
    img = Image.open(os.path.join(root, entry['src'])).convert('L')
    x0, y0, x1, y1 = entry['box']
    crop = img.crop((x0, y0, x1, y1))
    if 'keep' in entry:
        m = Image.new('L', crop.size, 0)
        ImageDraw.Draw(m).polygon([(x - x0, y - y0) for x, y in entry['keep']], fill=255)
        crop = Image.composite(crop, Image.new('L', crop.size, 255), m)
    ink = ink_mask(crop, entry.get('threshold', 140))
    sil = silhouette(ink, entry.get('close', 1), entry.get('open', 2))
    inner = interior_ink(ink, sil, entry.get('stroke', 3))
    sil_rings = [rdp(r, 0.4) for r in trace(sil)]
    ink_rings = [rdp(r, 0.4) for r in trace(inner, turd=4)]
    if not sil_rings:
        raise ValueError(f"{entry['id']}: empty silhouette")
    anchor = (entry['anchor'][0] - x0, entry['anchor'][1] - y0)
    extent = max(math.hypot(x - anchor[0], y - anchor[1]) for r in sil_rings for x, y in r)
    motif = {
        'id': entry['id'],
        'type': entry['type'],
        'presets': entry['presets'],
        'baseSize': entry['size'],
        'silhouette': [r for r in normalise(sil_rings, anchor, entry['angle'], extent) if len(r) >= 3],
        'ink': [r for r in normalise(ink_rings, anchor, entry['angle'], extent) if len(r) >= 3],
    }
    return motif, (crop, sil, inner, anchor, entry['angle'])


def preview_tile(entry, debug, tile=220):
    crop, sil, inner, anchor, angle = debug
    base = crop.convert('RGB')
    green = Image.new('RGB', base.size, (60, 170, 90))
    red = Image.new('RGB', base.size, (220, 40, 40))
    base = Image.composite(Image.blend(base, green, 0.45), base, sil)
    base = Image.composite(red, base, inner)
    d = ImageDraw.Draw(base)
    ax, ay = anchor
    d.ellipse([ax - 4, ay - 4, ax + 4, ay + 4], fill=(0, 0, 255))
    a = math.radians(angle)
    d.line([(ax, ay), (ax + math.cos(a) * 30, ay + math.sin(a) * 30)], fill=(0, 0, 255), width=2)
    base.thumbnail((tile, tile - 20))
    out = Image.new('RGB', (tile, tile), (255, 255, 255))
    out.paste(base, ((tile - base.width) // 2, 0))
    ImageDraw.Draw(out).text((4, tile - 16), f"{entry['id']} ({entry['type']})", fill=(0, 0, 0))
    return out


def main(argv):
    manifest = argv[1] if len(argv) > 1 else os.path.join(HERE, 'motif_regions.json')
    out_json = argv[2] if len(argv) > 2 else os.path.join(ROOT, 'prototype', 'assets', 'motifs.json')
    preview = argv[3] if len(argv) > 3 else os.path.join(HERE, 'out', 'preview.png')
    with open(manifest) as f:
        entries = json.load(f)
    motifs, tiles = [], []
    for entry in entries:
        motif, debug = process(entry)
        motifs.append(motif)
        tiles.append(preview_tile(entry, debug))
        print(f"{motif['id']}: {len(motif['silhouette'])} silhouette rings, {len(motif['ink'])} ink rings")
    os.makedirs(os.path.dirname(out_json), exist_ok=True)
    with open(out_json, 'w') as f:
        json.dump(motifs, f, separators=(',', ':'))
    cols = 4
    rows = (len(tiles) + cols - 1) // cols
    sheet = Image.new('RGB', (cols * 220, max(1, rows) * 220), (255, 255, 255))
    for i, t in enumerate(tiles):
        sheet.paste(t, ((i % cols) * 220, (i // cols) * 220))
    os.makedirs(os.path.dirname(preview), exist_ok=True)
    sheet.save(preview)
    print(f"wrote {len(motifs)} motifs to {out_json}; preview at {preview}")


if __name__ == '__main__':
    main(sys.argv)
```

```js
export function createMotifLibrary(list) {
  const byId = new Map();
  const byKey = new Map();
  for (const m of list) {
    byId.set(m.id, m);
    for (const set of m.presets) {
      const k = `${set}:${m.type}`;
      if (!byKey.has(k)) byKey.set(k, []);
      byKey.get(k).push(m);
    }
  }
  return {
    get: (id) => byId.get(id),
    has: (set, type) => byKey.has(`${set}:${type}`),
    pick: (set, type, rng) => {
      const arr = byKey.get(`${set}:${type}`);
      return arr ? rng.pick(arr) : null;
    },
  };
}

// Browser loader; an unavailable file degrades to procedural-only growth.
export async function loadMotifs(url) {
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return createMotifLibrary(await res.json());
  } catch (err) {
    console.warn('motifs unavailable, using procedural terminals only', err);
    return createMotifLibrary([]);
  }
}
```

```js
import { dist, ordered } from './geometry.js';
import { buildTendril, motifElement } from './tendril.js';
import { createNoise1D } from './noise.js';
import { smoothstep } from './shapes.js';

const MAX_PENDING = 2000;

function headingOf(points) {
  const a = points[0], b = points[points.length - 1];
  return Math.atan2(b.y - a.y, b.x - a.x);
}

// Consumes the sampled cursor path and grows spine strands, spawning tendrils, frills and blooms.
export class Grower {
  constructor({ scene, grid, params, rng, motifs }) {
    this.scene = scene;
    this.grid = grid;
    this.params = params;
    this.rng = rng;
    this.motifs = motifs;
    this.noise = createNoise1D(99);
    this.hasMotif = (type) => this.motifs.has(this.params.motifSet, type);
    this.pickMotif = (type, rng) => this.motifs.pick(this.params.motifSet, type, rng);
    this.reset();
  }

  reset() {
    this.pending = [];
    this.strand = null;
    this.lastTarget = null;
    this.curTarget = null;
    this.lastBloomAt = -Infinity;
  }

  setRng(rng) {
    this.rng = rng;
  }

  feed(points) {
    for (const p of points) this.pending.push(p);
    if (this.pending.length > MAX_PENDING) {
      const last = this.pending.length - 1;
      this.pending = this.pending.filter((p, i) => p.break || i % 2 === 0 || i === last);
    }
  }

  // The tip chases the target path at growSpeed, so fast flicks become sweeps that keep growing.
  update(dt, now, cursorSpeed) {
    let budget = this.params.growSpeed * dt;
    while (this.pending.length) {
      const p = this.pending[0];
      if (p.break) {
        this.pending.shift();
        this.endStrand(now);
        this.lastTarget = null;
        continue;
      }
      if (!this.lastTarget) {
        this.pending.shift();
        this.lastTarget = p;
        continue;
      }
      const d = dist(this.lastTarget, p);
      if (d <= budget) {
        budget -= d;
        this.pending.shift();
        this.advance(this.lastTarget, p, now);
        this.lastTarget = p;
        continue;
      }
      if (budget > 0) {
        const u = budget / d;
        const q = { x: this.lastTarget.x + (p.x - this.lastTarget.x) * u, y: this.lastTarget.y + (p.y - this.lastTarget.y) * u };
        this.advance(this.lastTarget, q, now);
        this.lastTarget = q;
      }
      break;
    }
    this.maybeBloom(dt, now, cursorSpeed);
  }

  advance(a, b, now) {
    const len = dist(a, b);
    if (len < 1e-6) return;
    if (!this.strand) this.startStrand(a, a, now);
    const st = this.strand, P = this.params;
    st.sTarget += len;
    this.curTarget = b;
    const hx = (b.x - a.x) / len, hy = (b.y - a.y) / len;
    const ramp = smoothstep(0, 150, st.sTarget);
    const off = P.meanderAmp * ramp * this.noise(st.sTarget / Math.max(1, P.meanderWavelength) + st.seed);
    const fade = 1 - smoothstep(0, 200, st.sTarget);
    this.appendSpinePoint({ x: b.x - hy * off + st.carry.x * fade, y: b.y + hx * off + st.carry.y * fade }, now);
  }

  startStrand(pos, target, now) {
    const P = this.params, rng = this.rng;
    const [lo, hi] = ordered(P.strandMin, P.strandMax);
    this.strand = {
      seed: rng.range(0, 500), points: [pos], s: 0, sTarget: 0, length: rng.range(lo, hi),
      nextSpawn: Math.max(20, P.tendrilSpacing) * rng.range(0.5, 1), lastSide: rng.sign(),
      carry: { x: pos.x - target.x, y: pos.y - target.y }, chunk: null,
    };
    this.ensureChunk(now);
  }

  // Spine growth inside one cohort window goes into one chunk; a new window starts a new chunk
  // that shares the seam point so the outline stays continuous.
  ensureChunk(now) {
    const st = this.strand, P = this.params;
    const cohort = this.scene.cohortFor('front', now, P.cohortWindow);
    if (st.chunk && st.chunk.cohort === cohort) return;
    if (st.chunk) {
      st.chunk.taperEnd = false;
      this.scene.touch(st.chunk.cohort);
    }
    const last = st.points[st.points.length - 1];
    st.chunk = {
      kind: 'ribbon', role: 'spine', points: [last], cum: [0], sOffset: st.s, seed: st.seed,
      taperEnd: true, born: now, growDuration: 0,
    };
    this.scene.add(st.chunk, 'front', now, P.cohortWindow);
  }

  appendSpinePoint(q, now) {
    const st = this.strand, P = this.params;
    const prev = st.points[st.points.length - 1];
    const step = dist(prev, q);
    if (step < 0.5) return;
    this.ensureChunk(now);
    st.points.push(q);
    if (st.points.length > 8) st.points.shift();
    st.s += step;
    const ch = st.chunk;
    ch.cum.push(ch.cum[ch.cum.length - 1] + step);
    ch.points.push(q);
    this.scene.touch(ch.cohort);
    while (st.s >= st.nextSpawn) {
      this.spawnAlongSpine(now);
      st.nextSpawn += Math.max(20, P.tendrilSpacing) * this.rng.range(0.7, 1.3);
    }
    if (st.s >= st.length) this.continueStrand(now);
  }

  tendrilOpts(extra) {
    return { params: this.params, rng: this.rng, hasMotif: this.hasMotif, pickMotif: this.pickMotif, scale: 1, ...extra };
  }

  addAll(els, track, now, at) {
    if (!els.length) return;
    els[0].cellKey = this.grid.add(at.x, at.y);
    for (const el of els) this.scene.add(el, track, now, this.params.cohortWindow);
  }

  crowded(at) {
    const P = this.params;
    return this.scene.count >= P.maxElements || this.grid.count(at.x, at.y) >= P.densityLimit;
  }

  spawnAlongSpine(now) {
    const st = this.strand, P = this.params, rng = this.rng;
    const tip = st.points[st.points.length - 1];
    if (this.crowded(tip)) return;
    const heading = headingOf(st.points);
    const side = rng.chance(P.alternateSides) ? -st.lastSide : st.lastSide;
    st.lastSide = side;
    if (rng.chance(P.tendrilChance)) {
      const track = rng.chance(P.backChance) ? 'back' : 'front';
      this.addAll(buildTendril(this.tendrilOpts({ x: tip.x, y: tip.y, heading, side, now })), track, now, tip);
    }
    if (P.frillChance > 0 && this.hasMotif('frill') && rng.chance(P.frillChance)) {
      const m = this.pickMotif('frill', rng);
      const half = P.spineWidth / 2;
      const nx = -Math.sin(heading) * -side, ny = Math.cos(heading) * -side;
      const angle = heading - side * (Math.PI / 2 - 0.7);
      this.addAll([motifElement(m, tip.x + nx * half, tip.y + ny * half, angle, 0.8, rng, now, 0.5)], 'front', now, tip);
    }
  }

  endStrand(now) {
    if (this.strand) this.finishStrand(now);
  }

  // Every free end gets a terminal: the strand tip turns into a short curling tendril.
  finishStrand(now) {
    const st = this.strand;
    this.strand = null;
    if (!st || st.s < 20) return;
    const tip = st.points[st.points.length - 1];
    const els = buildTendril(this.tendrilOpts({
      x: tip.x, y: tip.y, heading: headingOf(st.points), side: this.rng.sign(), scale: 0.9,
      length: this.rng.range(60, 140), loopBack: false, now,
    }));
    this.addAll(els, 'front', now, tip);
  }

  // Long strands end and a new one starts beside the old tip, overlapping it like the references.
  continueStrand(now) {
    const st = this.strand;
    const tip = st.points[st.points.length - 1];
    const heading = headingOf(st.points);
    const side = -st.lastSide;
    this.finishStrand(now);
    const off = this.params.spineWidth * 1.4 * side;
    const start = { x: tip.x - Math.sin(heading) * off, y: tip.y + Math.cos(heading) * off };
    this.startStrand(start, this.curTarget ?? tip, now);
  }

  maybeBloom(dt, now, speed) {
    const P = this.params, st = this.strand, rng = this.rng;
    if (!st || P.bloomRate <= 0 || !(speed < P.slowSpeed)) return;
    if (now - this.lastBloomAt < 0.8) return;
    if (!rng.chance(P.bloomRate * dt * (1 - speed / P.slowSpeed))) return;
    const type = this.hasMotif('bloom') ? 'bloom' : this.hasMotif('flower') ? 'flower' : null;
    if (!type) return;
    const tip = st.points[st.points.length - 1];
    if (this.crowded(tip)) return;
    this.lastBloomAt = now;
    const heading = headingOf(st.points);
    const side = rng.sign();
    const stem = buildTendril(this.tendrilOpts({
      x: tip.x, y: tip.y, heading, side, scale: 0.6, length: rng.range(50, 110), terminal: type, loopBack: false, now,
    }));
    const at = stem[0].points[stem[0].points.length - 1];
    const cluster = [];
    for (let i = 0; i < P.clusterTendrils; i++) {
      cluster.push(...buildTendril(this.tendrilOpts({
        x: at.x, y: at.y, heading: heading + (side * Math.PI) / 2 + rng.range(-1.4, 1.4), side: rng.sign(),
        scale: 0.45, terminal: rng.chance(0.5) ? 'curl' : 'ball', loopBack: false, now: now + 0.25 + i * 0.12,
      })));
    }
    this.addAll([...stem, ...cluster], 'front', now, tip);
  }
}
```

```js
const AGE_STEPS = 8;

function tracePoly(path, pts, closed) {
  if (pts.length < 2) return;
  path.moveTo(pts[0].x, pts[0].y);
  for (let i = 1; i < pts.length; i++) path.lineTo(pts[i].x, pts[i].y);
  if (closed) path.closePath();
}

function fit(canvas, pw, ph) {
  const c = canvas || document.createElement('canvas');
  if (c.width < pw || c.height < ph) {
    c.width = Math.max(pw, Math.ceil(c.width * 1.25));
    c.height = Math.max(ph, Math.ceil(c.height * 1.25));
  }
  return c;
}

function reset(g, pw, ph) {
  g.setTransform(1, 0, 0, 1, 0, 0);
  g.globalCompositeOperation = 'source-over';
  g.globalAlpha = 1;
  g.filter = 'none';
  g.clearRect(0, 0, pw, ph);
}

// Each shape is filled separately: winding directions differ between shapes, so one shared
// nonzero path could cancel overlaps into holes.
function fillInteriors(g, shapes) {
  for (const s of shapes) {
    const p = new Path2D();
    for (const r of s.fill.rings) tracePoly(p, r, true);
    g.fill(p, s.fill.rule);
  }
}

// Stroke at 2× ink weight, then erase (or paint over) interiors: only the outer edge of the
// union of all shapes survives, so overlapping ribbons fuse.
function drawShapes(g, shapes, P, colour, cut) {
  g.lineJoin = 'round';
  g.lineCap = 'round';
  g.strokeStyle = colour;
  g.lineWidth = P.inkWeight * 2;
  const outline = new Path2D();
  for (const s of shapes) for (const run of s.runs) tracePoly(outline, run.points, run.closed);
  g.stroke(outline);
  if (cut) {
    g.globalCompositeOperation = 'destination-out';
    g.fillStyle = '#000';
  } else {
    g.fillStyle = P.fill;
  }
  fillInteriors(g, shapes);
  g.globalCompositeOperation = 'source-over';
  g.fillStyle = colour;
  const ink = new Path2D();
  let any = false;
  for (const s of shapes) if (s.ink) for (const r of s.ink) { tracePoly(ink, r, true); any = true; }
  if (any) g.fill(ink, 'evenodd');
}

    this.scene = scene;
    this.params = params;
    this.motifs = motifs;

    this.dpr = 1;

    this.canvas.style.height = `${h}px`;
    this.invalidate();
  }

  invalidate() {
    this.paramsVersion++;
  }

  render(now) {
    const { ctx, params: P, dpr } = this;
    reset(ctx, this.canvas.width, this.canvas.height);
    const cohorts = this.scene.cohorts;
    const ordered = [...cohorts.filter((c) => c.track === 'back'), ...cohorts.filter((c) => c.track === 'front')];
    for (const c of ordered) {
      const age = now - c.start;
      const alpha = cohortAlpha(age, P.lifetime, P.fadeStart);
      if (alpha <= 0) continue;
      const step = ageStep(age, P.lifetime, AGE_STEPS);

      }
      if (!rs.bbox) continue;
      const dx = Math.round(rs.bbox.x * dpr), dy = Math.round(rs.bbox.y * dpr);
      ctx.globalAlpha = alpha;
      if (rs.mask) {
        // Occlusion: newer growth hides older lines beneath its interiors.
        ctx.globalCompositeOperation = 'destination-out';
        ctx.drawImage(rs.mask, 0, 0, rs.pw, rs.ph, dx, dy, rs.pw, rs.ph);
      }
      ctx.globalCompositeOperation = 'source-over';
      ctx.drawImage(rs.lines, 0, 0, rs.pw, rs.ph, dx, dy, rs.pw, rs.ph);
    }
    ctx.globalAlpha = 1;
    ctx.globalCompositeOperation = 'source-over';
  }

  shapeFor(el, now) {
    if (el.kind === 'ribbon') return ribbonShape(el, this.params, this.noise, now);
    if (el.kind === 'blob') return blobShape(el, this.params, this.noise, now);
    if (el.kind === 'motif') return motifShape(el, this.motifs.get(el.id), this.params, now);
    return null;
  }

  colourFor(track, step) {
    const P = this.params;
    const base = track === 'back' ? P.backMix : 0;
    return mixHex(P.ink, P.paper, base + (1 - base) * P.ageTint * (step / AGE_STEPS));
  }

  renderCohort(c, rs, now, step) {
    const P = this.params, dpr = this.dpr;
    const shapes = [];
    for (const el of c.elements) {
      const s = this.shapeFor(el, now);
      if (s) shapes.push(s);
    }
    if (!shapes.length) {
      rs.bbox = null;
      return;
    }
    const blur = P.blurMax * (step / AGE_STEPS) + (c.track === 'back' ? P.blurMax * 0.5 : 0);
    const pad = P.inkWeight * 2 + blur * 3 + 4;
    const b = shapeBounds(shapes);
    const x0 = Math.floor(b.minX - pad), y0 = Math.floor(b.minY - pad);
    const pw = Math.ceil((Math.ceil(b.maxX + pad) - x0) * dpr);
    const ph = Math.ceil((Math.ceil(b.maxY + pad) - y0) * dpr);
    const cut = P.fillMode !== 'fill';
    rs.lines = fit(rs.lines, pw, ph);
    rs.mask = cut ? fit(rs.mask, pw, ph) : null;
    rs.bbox = { x: x0, y: y0 };
    rs.pw = pw;
    rs.ph = ph;
    const colour = this.colourFor(c.track, step);

    const g = rs.lines.getContext('2d');
    reset(g, pw, ph);
    g.setTransform(dpr, 0, 0, dpr, -x0 * dpr, -y0 * dpr);
    drawShapes(g, shapes, P, colour, cut);
    if (blur > 0.05) this.blurInPlace(rs.lines, pw, ph, blur * dpr);

    if (cut) {
      const m = rs.mask.getContext('2d');
      reset(m, pw, ph);
      m.setTransform(dpr, 0, 0, dpr, -x0 * dpr, -y0 * dpr);
      m.fillStyle = '#000';
      fillInteriors(m, shapes);
    }
  }

  // Re-rendered from crisp shapes at every age step, so blur never accumulates.
  blurInPlace(canvas, pw, ph, px) {
    this.scratch = fit(this.scratch, pw, ph);
    const sg = this.scratch.getContext('2d');
    reset(sg, pw, ph);
    sg.drawImage(canvas, 0, 0, pw, ph, 0, 0, pw, ph);
    const g = canvas.getContext('2d');
    reset(g, pw, ph);
    g.filter = `blur(${px.toFixed(2)}px)`;
    g.drawImage(this.scratch, 0, 0, pw, ph, 0, 0, pw, ph);
    g.filter = 'none';
  }
}
```

```js
import { createRng } from './rng.js';
import { Scene, DensityGrid } from './scene.js';
import { Grower } from './grower.js';
import { PathSampler, Smoother, autoDrawPosition, clampDt } from './input.js';
import { Renderer } from './render.js';
import { PRESETS, SCHEMA, presetValues, sanitize } from './presets.js';
import { loadMotifs } from './motifs.js';

const FIXED_DT = 1 / 60;
const query = new URLSearchParams(location.search);
const state = {
  presetName: query.get('preset') in PRESETS ? query.get('preset') : 'ribbon',
  seed: Number(query.get('seed')) || 1,
  autoDraw: query.get('autodraw') === '1',
  fixedStep: query.get('fixedstep') === '1',
};

const params = presetValues(state.presetName);
const motifs = await loadMotifs('assets/motifs.json');
const scene = new Scene();
const grid = new DensityGrid(48);
const grower = new Grower({ scene, grid, params, rng: createRng(state.seed), motifs });
const sampler = new PathSampler(3, 220);
const smoother = new Smoother();
const renderer = new Renderer(document.getElementById('stage'), { scene, params, motifs });

let pointer = null;
let simTime = 0;
let autoTime = 0;
let staticMode = false;

function lift() {
  pointer = null;
  sampler.breakStrand();
  smoother.reset();
}
window.addEventListener('pointermove', (e) => {
  if (e.target instanceof Element && e.target.closest('#panel')) {
    if (pointer) lift();
    return;
  }
  pointer = { x: e.clientX, y: e.clientY };
});
document.documentElement.addEventListener('pointerleave', lift);
window.addEventListener('blur', lift);

function applyPaper() {
  document.body.style.background = params.paper;
}
function resize() {
  renderer.resize(window.innerWidth, window.innerHeight, window.devicePixelRatio || 1);
  if (staticMode) renderer.render(simTime);
}
window.addEventListener('resize', resize);

function clearAll() {
  scene.clear();
  grid.clear();
  grower.reset();
  sampler.breakStrand();
  smoother.reset();
}

function step(dt) {
  simTime += dt;
  let target = pointer;
  if (state.autoDraw) {
    autoTime += dt;
    target = autoDrawPosition(autoTime, renderer.w, renderer.h, state.seed);
  }
  if (target) {
    const p = smoother.update(target, dt, params.smoothing);
    sampler.push(p.x, p.y);
  }
  grower.feed(sampler.take());
  grower.update(dt, simTime, target ? smoother.speed : Infinity);
  for (const c of scene.cull(simTime, params.lifetime)) {
    for (const el of c.elements) if (el.cellKey) grid.remove(el.cellKey);
  }
}

const actions = {
  param(key, value, live) {
    if (live) renderer.invalidate();
    if (key === 'paper') applyPaper();
  },
  preset(name) {
    state.presetName = name;
    Object.assign(params, presetValues(name));
    renderer.invalidate();
    applyPaper();
    panel.refresh();
  },
  seed(seed) {
    state.seed = seed;
    grower.setRng(createRng(seed));
  },
  clear: clearAll,
  autoDraw(on) {
    state.autoDraw = on;
    if (!on) {
      sampler.breakStrand();
      smoother.reset();
    }
  },
  load(obj) {
    for (const def of SCHEMA) {
      if (!(def.key in obj)) continue;
      const v = sanitize(def, obj[def.key]);
      if (v !== null) params[def.key] = v;
    }
    renderer.invalidate();
    applyPaper();
    panel.refresh();
  },
};

// Replaced by createPanel in Task 11.
const panel = { refresh() {}, setFps() {} };

window.__floral = { state, params, scene, renderer, step, actions, fps: 0, get simTime() { return simTime; } };

resize();
applyPaper();
const warmup = Number(query.get('warmup')) || 0;
for (let i = 0; i < Math.round(warmup / FIXED_DT); i++) step(FIXED_DT);

const reducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
if (reducedMotion && !warmup) {
  const wasAuto = state.autoDraw;
  state.autoDraw = true;
  for (let i = 0; i < 300; i++) step(FIXED_DT);
  state.autoDraw = wasAuto;
}

if (reducedMotion || query.get('pause') === '1') {
  staticMode = true;
  renderer.render(simTime);
} else {
  let last = performance.now();
  let fps = 60;
  let frames = 0;
  const frame = (t) => {
    const raw = (t - last) / 1000;
    last = t;
    step(state.fixedStep ? FIXED_DT : clampDt(raw));
    renderer.render(simTime);
    if (raw > 0) fps += (1 / raw - fps) * 0.05;
    window.__floral.fps = fps;
    if (++frames % 15 === 0) panel.setFps(fps);
    requestAnimationFrame(frame);
  };
  requestAnimationFrame(frame);
}
```

```js
import { SCHEMA, GROUPS, PRESETS } from './presets.js';

function h(tag, attrs = {}, ...children) {
  const n = document.createElement(tag);
  for (const [k, v] of Object.entries(attrs)) {
    if (k.startsWith('on')) n.addEventListener(k.slice(2), v);
    else if (k === 'class') n.className = v;
    else n.setAttribute(k, v);
  }
  for (const c of children) if (c !== null && c !== undefined) n.append(c);
  return n;
}

const decimals = (step) => (String(step).includes('.') ? String(step).split('.')[1].length : 0);

// Builds the top bar from the parameter schema, so every tunable gets a control automatically.
export function createPanel(root, { params, state, on }) {
  const inputs = [];
  const fps = h('span', { class: 'fps' }, '-- fps');

  const presetSel = h('select', { title: 'Preset', onchange: () => on.preset(presetSel.value) },
    ...Object.keys(PRESETS).map((n) => h('option', { value: n }, n)));
  const seedIn = h('input', { type: 'number', class: 'seed', title: 'Seed', value: String(state.seed) });
  const auto = h('input', { type: 'checkbox', onchange: () => on.autoDraw(auto.checked) });
  auto.checked = state.autoDraw;

  const groups = h('div', { class: 'groups' });
  for (const group of GROUPS) {
    const body = h('div', { class: 'controls' });
    for (const def of SCHEMA.filter((d) => d.group === group)) body.append(control(def));
    const det = h('details', {}, h('summary', {}, group), body);
    det.addEventListener('toggle', () => {
      if (!det.open) return;
      for (const other of groups.querySelectorAll('details')) if (other !== det) other.open = false;
    });
    groups.append(det);
  }

  const bar = h('div', { class: 'bar' },
    h('button', { class: 'collapse', title: 'Collapse panel', onclick: () => root.classList.toggle('collapsed') }, '☰'),
    h('label', {}, 'Preset ', presetSel),
    h('button', { onclick: () => on.preset(presetSel.value) }, 'Reset to preset'),
    h('label', {}, 'Seed ', seedIn),
    h('button', { onclick: () => on.seed(Number(seedIn.value) || 1) }, 'Re-seed'),
    h('button', { onclick: () => on.clear() }, 'Clear canvas'),
    h('label', {}, auto, ' Auto-draw'),
    h('button', { onclick: copySettings }, 'Copy settings'),
    h('button', { onclick: pasteSettings }, 'Paste settings'),
    fps,
    groups,
  );
  root.replaceChildren(bar);

  function control(def) {
    let input;
    if (def.type === 'range') input = h('input', { type: 'range', min: def.min, max: def.max, step: def.step });
    else if (def.type === 'color') input = h('input', { type: 'color' });
    else input = h('select', {}, ...def.options.map((o) => h('option', { value: o }, o)));
    const out = h('output', {});
    input.addEventListener('input', () => {
      const v = def.type === 'range' ? Number(input.value) : input.value;
      params[def.key] = v;
      show(def, input, out);
      on.param(def.key, v, def.live);
    });
    inputs.push({ def, input, out });
    const tag = def.live ? null : h('span', { class: 'tag', title: 'Affects new growth only' }, 'new');
    return h('label', { class: 'control' }, h('span', { class: 'name' }, def.label, tag), input, out);
  }

  function show(def, input, out) {
    out.textContent = def.type === 'range' ? Number(input.value).toFixed(decimals(def.step)) : input.value;
  }

  function refresh() {
    presetSel.value = state.presetName;
    for (const { def, input, out } of inputs) {
      input.value = String(params[def.key]);
      show(def, input, out);
    }
  }

  async function copySettings() {
    const json = JSON.stringify(params, null, 2);
    try {
      await navigator.clipboard.writeText(json);
      fps.textContent = 'copied';
    } catch {
      window.prompt('Copy settings:', json);
    }
  }

  async function pasteSettings() {
    let text = null;
    try {
      text = await navigator.clipboard.readText();
    } catch {
      text = window.prompt('Paste settings JSON:');
    }
    if (!text) return;
    try {
      on.load(JSON.parse(text));
    } catch {
      fps.textContent = 'invalid JSON';
    }
  }

  refresh();
  return {
    refresh,
    setFps: (n) => { fps.textContent = `${Math.round(n)} fps`; },
  };
}
```
